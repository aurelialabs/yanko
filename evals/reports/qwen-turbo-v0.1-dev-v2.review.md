## 关键结论

1. 第一轮最严重的跨角色私密记忆泄漏已在 v0.2 报告中消失，但主要功劳属于服务端确定性输入过滤；这条防线必须保留，不能退回让模型自由决定作用域。
2. 敏感记忆错误共享和不完整高风险回复现在会 fail closed，说明输出边界有效；但“阻断”不等于“能力通过”，真实链路还必须提供确定性安全兜底或受控重写。
3. qwen-turbo 在 OOC verdict、计划分类、人设庆祝语气和延迟方面有改善，仍未达到可接入产品聊天的门槛。
4. 计划提取、记忆抽取和记忆召回仍是主要质量短板。自然周、标准化键、最大召回数等确定性规则不应继续完全依赖模型生成。
5. 目前不应运行冻结 test，也不应形成 G2 通过结论。

## 建议的下一步

先准备 `yanxing-eval-v0.3`，但在获得明确复核后才进行下一次付费 dev 调用：

1. 把自然周边界、提醒默认提前量、层级允许字段、标准化记忆键和最大召回数收口到确定性代码；
2. 为高风险回复加入固定安全兜底或一次受控重写，保证 gate 阻断后仍有可发送的安全响应；
3. 修正 OOC 标签提示与情绪回访规则；
4. 用同一组 32 条 dev 验证关键硬失败为零后，再冻结统一 Prompt／策略版本并引入第二候选；
5. 两个候选在相同快照、Prompt 和策略版本下完成 dev 横评后，才决定是否解锁 48 条冻结 test。

在上述条件完成前，结论保持为：**不运行冻结 test、不接产品聊天、不设置默认模型。**
